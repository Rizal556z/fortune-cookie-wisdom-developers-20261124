## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one original line of fortune-cookie wisdom for a software
developer to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The line

**"Your lucky number is the line count of the function you finally deleted."** — it opens like a real fortune cookie ("Your lucky number is..."), then turns the number into something every developer knows: the quiet satisfaction of deleting code. The best code you write today may be the code you remove.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fortune-test python3 main.py
cat /tmp/fortune-test/entry.txt
```
